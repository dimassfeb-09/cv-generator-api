1. Generate & Save CV

/api/generate

Endpoint ini melakukan validasi data, pembuatan PDF, upload cloud storage, dan penyimpanan ke PostgreSQL.

2. Get Full CV Details

Mengambil semua data dari database. Perhatikan format respons yang menyertakan bullets dalam bentuk array JSON.

3. Fetch CV History by Email

/api/cv/user/:email

Mendapatkan daftar semua CV yang pernah dibuat oleh user berdasarkan alamat email mereka.

Response Example (Success - 200 OK)

{
  "success": true,
  "count": 2,
